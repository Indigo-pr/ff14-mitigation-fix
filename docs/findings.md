# ログ解析でわかったこと

検証に使ったログ: 2026-09-07 / 零式アナザーダンジョン シラディハ水路（Another Sil'dihn Subterrane Savage）
シルキー戦 1トライ・320秒・全滅。PT構成 PLD / RPR / SMN / SGE。

---

## 1. ACTログの生ダメージは「軽減後」の値しかない

ACTのネットワークログ（21/22行）に記録されるダメージは、サーバーが最終計算した結果。
**軽減前の値はクライアントに送られてこないのでログには存在しない。**

一方 FFLogs は `unmitigatedAmount` を自前で計算して持っている。
Damage Taken タブの **U (Unmitigated)** 列がそれで、定義は
"how much damage the attack would have done with no shields and mitigation"。

→ 素ダメージが欲しいなら FFLogs V2 API を使うのが唯一の現実解。

## 2. FFLogsは1ヒットにつき2行返す

`calculateddamage`（スナップショット）と `damage`（実適用）が約1秒差で出る。

| | unmitigatedAmount | mitigated | absorbed |
|---|---:|---:|---:|
| スナップショット行 | 91,126 | 0 | 0 |
| 実適用行 | 110,193 | 54,657 | 9,609 |

**スナップショット行は軽減欄が空で、バリア吸収分も素ダメージに含まれない**ため、
そのまま使うと過小評価になる。

判別式:

```
素ダメージ = 実ダメージ + バリア吸収 + 軽減量
```

これが成立する行だけを採用する。440行 → 83行まで落ちる。

## 3. ACTログのダメージ復号

`21|...|<flags>|<damage>|...` の damage フィールドは、先頭の16進数が実ダメージ。

```python
def unscramble(field):
    if len(field) <= 4: return 0
    d = int(field[:-4], 16)
    if field[-4] == '4':          # 65535超のときのフラグ
        r = int(field[-2:], 16)
        d = d - r + (r << 16)
    return d
```

flags の下位ニブルが結果種別で、**3=通常 / 5=ブロック / 6=受け流し / 4=回復 / 1=回避 / 0x1B=ステータス付与のみ**。
`0x1B` の行は damage フィールドに **アビリティIDが入っている**ため、ダメージとして拾うと誤カウントする。

検証: ボスHPの実減少 9,639,820 に対し復号ダメージ合計 8,529,805。差の11%はDoTティック分で説明がつく。

## 4. ダメージのばらつきは4要因

同じ技を同じ人が食らった時の幅:

```
水洗い    RPR  [54,438 / 54,910 / 56,628]   幅 4.0%
水洗い    SGE  [50,511 / 51,104 / 52,929]   幅 4.8%
水洗い    SMN  [50,369 / 50,753 / 53,019]   幅 5.3%
カーペットビーター PLD [104,994 / 110,193]      幅 5.0%
```

| 要因 | 影響 |
|---|---|
| **ダメージ乱数** | **±5%**（仕様。消せない） |
| 頭割り人数 | 35〜86% |
| ブロック / 受け流し | タンクのみ。**ブロック20% / 受け流し15%**（実測で確定） |
| ジョブ別防御力 | 対象間で最大25%（水洗い: PLD 41,989 / RPR 56,628） |

**敵の攻撃にクリティカルは発生していない。** 被弾161件のヒット種別を全数調査した結果:

| hitType | 件数 | 正体 |
|---|---:|---|
| 1 | 111 | 通常 |
| 4 | 41 | ブロック（ちょうど20%軽減・全部タンク） |
| 20 | 9 | 受け流し（ちょうど15%軽減・全部タンク） |

クリティカル該当は0件。

## 5. 頭割りは正確に 1/N

「1人あたりのダメージ × 対象人数」が、人数をまたいで揃う。

```
ID     秒  人数  各人の素ダメージ → 1人換算
30595 295   4   RPR 52,354→209,416  SGE 49,439→197,756  SMN 48,622→194,488
30597 368   3   RPR 71,749→215,247  SMN 65,980→197,940
30595 437   3   RPR 74,576→223,728  SGE 69,209→207,627
30596 527   2   SMN 94,969→189,938  PLD 64,118→128,236
30596 543   3   RPR 72,946→218,838  SGE 64,247→192,741
```

| ジョブ | 1人換算のばらつき |
|---|---|
| RPR | 209,416 〜 223,728（幅 6.8%） |
| SGE | 192,741 〜 207,627（幅 7.7%） |
| SMN | 189,938 〜 197,940（幅 4.2%） |
| PLD | 128,236 〜 138,339（幅 7.9%） |

残った幅は全部±5%の乱数。技ID3種・人数3パターンをまたいで揃うので 1/N は確実。

> **重要**: 比較は「同じ人の値が回をまたいで揃うか」で見ること。
> 人をまたいで比べるとジョブ間の防御力差（最大25%）で揺れて判定に失敗する。

## 6. 軽減スキルの実測値

FFLogsの素ダメージと実ダメージの比から逆算したもの。

| スキル | 軽減率 | 備考 |
|---|---:|---|
| センチネル | 30% | |
| ホーリズム | 10% | |
| ホーリーシェルトロン | 15% | |
| **ナイトの堅守** | 15% | ホーリーシェルトロンが付与する4秒バフ |
| **ナイトの加護** | **0%** | **軽減ではない。リジェネ効果** |

`ナイトの加護` が乗った状態のAAが軽減なしの最大値を上回った（15,327 > 14,768）ことから発覚。
FFLogsが軽減・バリアとして記録するバフ一覧にも Knight's Benediction は含まれていない。

検算例（カーペットビーター）:

```
素 110,193 × センチネル0.7 × ケーラコレ0.9 = 69,422
           − ブロック 13,885 = 55,537
                            ＝ 実ダメージ 45,927 + バリア吸収 9,609 ✅
```

## 7. ジェネレーターのDamage値のずれ

軽減表ジェネレーター v7.4 の自動生成結果と、FFLogs素ダメージの突き合わせ。

**単体対象の技は1の位まで完全一致する。** 複数対象になるとずれる。

| 技名 | ジェネレーター | 実測(素ダメ) | 比 |
|---|---:|---:|---:|
| ダストブロワー | 11,896 | 11,896 | ✅ |
| 水拭き | 56,485 | 56,485 | ✅ |
| ひえひえダスター | 58,399 | 58,399 | ✅ |
| ポンポンはたきがけ | 46,032 | 46,032 | ✅ |
| **カーペットビーター** | 155,098 | 110,193 | **×1.41** |
| **カーペットビーター** | 131,243 | 104,994 | **×1.25** |
| すべってシャンプーボム | 43,003 | 52,354 | ×0.82 |
| すべってシャンプーボム | 56,515 | 71,749 | ×0.79 |
| すべってシャンプーボム | 54,508 | 74,576 | ×0.73 |
| そよそよダスター | 53,216 | 60,108 | ×0.89 |
| 水洗い | 42,705 | 56,628 | ×0.75 |
| ダストブロワー | 0 | 12,610 | — |

- タンク強攻撃はブロック分を割り戻そうとして**過大**になる
- 頭割り・全体は**過小**になる（こちらが危険。表の上では足りているのに実戦で落ちる）

> ジェネレーター側は正しく `unmitigatedAmount` を使っている（単体技が完全一致することから確定）。
> 複数対象のときの集計方法に問題があると思われる。

## 8. その他

- 技名 `unknown_79fb` 等は **16進のアビリティID**（0x79FB = 31227）。
  `0x1B` フラグ行のダメージ欄に入っていたのもこのID
- 水洗いには **DoT成分**がある（約26,000 × 4tick）。ジェネレーターは拾っている
- すべってシャンプーボムは属性違いで **技IDが3つ**（30595 / 30596 / 30597）に分かれる
- そよそよダスターは**シルキー本体とシルキーズ・ポンポンの両方**が使い、性質が別物
